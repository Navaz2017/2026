# Languages (Chichewa, Tumbuka, English)

Source of truth: `shared/i18n/{en,ny,tum}.json` (371 strings). `node shared/i18n/sync.mjs` verifies every language has
every key, no empty values, and identical `{placeholders}`, then copies the files into `web/src/i18n` and `mobile/src/i18n`.
Run it in CI. To add a language (e.g. Chiyao, Chisena): add `xx.json`, add it to `LANGS` in `web/src/lib/i18n.tsx` /
`mobile/src/i18n.ts` and `lang.xx` keys, add `"xx"` to the Zod enums in `backend/src/routes/auth.ts`.

## How it behaves
- The language buttons (shown in each language's own name) are on the login page, sign-up page and top bar of every screen.
- Choosing one switches **all** menus, buttons, statuses, errors, notifications and defaults at once.
- The choice is remembered on the device and saved to the account, so it follows the user to a new device.
- Server messages are translated on the client by *code* (`err.reference_already_used`, `notif.PAYMENT_CONFIRMED`, …) so
  the same API serves every language. Default decision letters are also sent in the applicant's language
  (`backend/src/lib/letters.ts`); an institution's own template always wins.
- Missing translation → falls back to English, never a blank.

## ⚠️ Translation quality — needs native review before launch
These translations were drafted by an AI assistant, not by professional translators. Chichewa is likely closer to usable;
**Chitumbuka is a best-effort draft and WILL contain mistakes** (vocabulary, spelling, tone-marks like ŵ). For parents who
cannot read English, wrong wording on payments or consent screens is a real risk. Before launch:
1. Have 2 native speakers per language review `ny.json` / `tum.json` (a spreadsheet export works — keys in column A).
2. Pay particular attention to: `auth.consent`, `fam.payHow`, `fam.afterPay`, `st.*`, `err.*`, `notif.*` and the default letters in `letters.ts`.
3. Test with real low-literacy users (icons are paired with every menu entry; consider audio help later).
4. Legal wording (consent / data protection) should be reviewed by a lawyer in each language.
